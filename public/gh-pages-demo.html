Acesso, chave da IA e varredura das lojas

Você já entrou com e-mail e senha. Falta só dizer de onde vem a IA: este site não traz chave embutida (o GitHub bloqueia chave de API no código público), então escolha uma das rotas. Tudo aqui fica salvo no seu navegador — nada é enviado para um servidor nosso.

  1. Sua chave, uma vez: gere em aistudio.google.com/apikey e cole em Chave da IA. Nunca mais é pedida neste dispositivo (e vale para o seu e-mail cadastrado na tela de acesso).
  2. Chave para todos os visitantes: crie o secret GEMINI_API_KEY em Settings → Secrets and variables → Actions e deixe o workflow pages.yml ativo na branch que o Pages publica — o deploy injeta a chave no arquivo publicado, sem ela nunca ir ao repositório.
  3. Servidor (recomendado): publique pages-proxy/worker.js num Cloudflare Worker grátis e cole a URL em Servidor. A chave fica só no Worker (o HTML não leva nada), a IA é chamada por ele, o login é validado por ele e a varredura das lojas também. Sem esse campo, a varredura depende dos proxies CORS públicos, hoje instáveis.
